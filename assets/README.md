# Quil assets

- `quil-logo.jpg`: source logo supplied for Quil.
- `chime-start.wav`, `chime-stop.wav`: original, locally synthesized notification sounds generated by `scripts/generate_chimes.py`. They contain only sine tones and envelopes, not samples, voices, or third-party recordings. They are released under the same MIT License as Quil.

`quil dictate` plays the start/stop chimes through the local macOS `afplay` utility, with no network access. Use `--no-chime` to disable them. `QUIL_ASSET_DIR` may point to a directory containing replacement files with the same names; the installer places the stock files in `~/.local/share/quil/assets`.
